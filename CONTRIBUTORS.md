## How to Contribute

We welcome all types of contributions:

- 💻 **Code**: Bug fixes, features, improvements
- 📝 **Documentation**: Guides, tutorials, examples
- 🐛 **Testing**: Bug reports, testing new features
- 💡 **Ideas**: Feature requests, suggestions
- 🎨 **Design**: UI/UX improvements, icons
- 🌍 **Translation**: Help make ConTextCap multilingual
- 📢 **Advocacy**: Blog posts, talks, social media

See our [Contributing Guide](CONTRIBUTING.md) to get started!

## Recognition System

### Contribution Badges

Contributors earn badges for their contributions:

- 🌟 **First Contribution**: Made your first PR
- 🐛 **Bug Hunter**: Reported a valid bug
- 💡 **Idea Generator**: Suggested an implemented feature
- 📚 **Documentation Hero**: Significantly improved docs
- 🧪 **Test Master**: Added comprehensive tests
- 🎨 **Design Wizard**: Enhanced UI/UX
- 🚀 **Performance Booster**: Improved performance
- 🔒 **Security Guardian**: Reported/fixed security issues
- 💬 **Community Champion**: Actively helps in discussions
- ⭐ **Star Contributor**: Made 10+ significant contributions
