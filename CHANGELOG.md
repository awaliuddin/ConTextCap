# Changelog

All notable changes to ConTextCap will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [Unreleased]

### Added
- Production-grade CI/CD pipeline with GitHub Actions
- Comprehensive testing infrastructure with pytest
- Code quality automation (black, isort, flake8, mypy, bandit)
- Automated community engagement workflows
- Enhanced issue and PR templates
- Comprehensive documentation (User Guide, Developer Guide, Security Policy)
- Dependabot configuration for automated dependency updates
- Pre-commit hooks for code quality
- Package distribution setup (setup.py, pyproject.toml)
- Code coverage reporting with Codecov integration

### Changed
- Enhanced README with comprehensive badges and information
- Updated Python requirement to 3.8+
- Improved project structure and organization

### Fixed
- Various code quality improvements

## [1.0.0] - 2024-01-XX

### Added
- Initial release of ConTextCap
- Directory tree visualization
- Code content capture for text files
- Binary file information display
- Customizable icon styles (Classic, Vivid, High-Contrast, Square-O)
- Smart file filtering
- Modern PyQt6 UI
- Progress tracking for large projects
- PDF generation with fpdf2

### Features
- Support for multiple file types (.py, .js, .json, .md, .txt, etc.)
- Automatic exclusion of common non-essential directories
- Clean and intuitive user interface
- Error handling and user-friendly messages
